# 말걸음 백엔드 구현 계획

## v1의 완료 기준

로그인한 사용자가 리허설 또는 실전에서 음성 시작을 선택하면, 앱은 Firebase ID 토큰으로 단기 자격증명을 받고 OpenAI와 WebRTC 연결을 연다. 발급이 실패해도 로컬 대본과 타이머로 수동 진행할 수 있다. 기획 FR-10·14·19·20, Figma S-03-R·S-06·S-08-M과 [v1 연동 계약](contract-v1.md)을 기준으로 한다.

| 순서 | 구현 범위 | 확인할 결과 |
| --- | --- | --- |
| 1. HTTP와 인증 | 기존 `GET /health` 유지. 본문 없는 발급 요청에서 Firebase Admin SDK로 Bearer 토큰을 검증하고 UID를 얻는다. | 토큰 누락·만료·다른 프로젝트는 401. 거부된 요청은 OpenAI에 도달하지 않는다. |
| 2. 발급 횟수 제한 | 검증된 UID별로 발급 시도를 원자적으로 집계한다. 로컬 워커 한 개는 메모리, 여러 워커·인스턴스는 같은 Redis를 사용한다. | 같은 UID의 동시 요청도 한도를 지킨다. 429에 남은 대기 초가 있고, 저장소 장애 시 발급을 보류한다. |
| 3. OpenAI 연동 | FastAPI가 서버 키와 고정한 한국어 전사 설정으로 단기 자격증명을 요청한다. 공급자 오류를 앱의 복구 정책에 맞게 변환한다. | 성공 응답에는 단기 키와 만료 시각만 있다. 할당량·설정 오류와 일시 장애를 구분한다. |
| 4. 클라이언트 통합 | 테스트베드의 기존 발급 프록시와 같은 계약을 Android에서도 사용한다. 앱이 마이크 트랙·이벤트 채널을 열고 SDP를 OpenAI와 교환한다. | API 명세와 실행 응답이 일치한다. 수동 시작은 발급 0회이고 재연결은 새 토큰을 사용한다. |
| 5. 실환경 인수 | 같은 Firebase 프로젝트의 테스트 계정과 실제 발급 키로 로그인부터 한 문장 전사까지 확인한 뒤 Android에서 5분 한국어 대본을 시험한다. | 발화 종료 후 완료 이벤트, 연결 단절 중 타이머 유지, 수동 전환 후 중복 통과 0건을 확인한다. |

## 운영 경계

FastAPI에는 인증과 발급용 HTTPS 요청만 들어온다. 대본·계획 버전·통과 이력은 기기의 Room이 소유하고, 마이크 음성과 전사 이벤트는 앱과 OpenAI가 직접 주고받는다. 배포 시 서버 비밀값, Firebase 프로젝트, HTTPS 주소를 설정하고 여러 프로세스는 동일한 발급 카운터를 사용한다.

## 2026-11-20 검증 현황

| 대상 | 결과 |
| --- | --- |
| HTTP·Firebase 검증 | FastAPI와 실제 Firebase Admin SDK에 로컬 서명 토큰을 입력했다. 정상 토큰은 발급 경로를 통과했고, 만료·서명 오류·다른 프로젝트·취소·비활성 계정은 모두 401이며 OpenAI 호출은 0건이었다. Google 인증서와 사용자 조회 응답에는 테스트 데이터를 사용했다. |
| 발급 횟수 제한 | 로컬 기본값에서 같은 UID의 동시 요청 12건 중 5건만 성공했다. 임시 Redis에 독립된 제한기 두 개를 연결한 시험에서는 2초당 3회 설정으로 12건 중 3건만 통과했다. 다른 UID, 창 만료 후 재발급, Redis 중단 시 503을 확인했다. |
| 실제 WebRTC | 테스트베드 API 모드 → FastAPI → OpenAI 발급이 200, SDP 교환이 201이었다. Chromium에서 3.63초짜리 합성 한국어 음성을 마이크 트랙에 넣어 전사 부분 결과 6개와 한국어 완료 결과를 받았다. 이 시험의 Firebase 로그인·공개 키·계정 조회 응답은 로컬 테스트 데이터였다. |
| 실제 Firebase와 발급 | 테스트에 사용한 Firebase 프로젝트에서 이메일 가입과 비밀번호 로그인이 각각 200이었다. 발급 전용 서비스 계정에 Firebase Authentication Viewer 역할을 부여했다. 로그인 ID 토큰으로 로컬 테스트베드 프록시와 FastAPI를 거쳐 실제 OpenAI 단기 자격증명을 받았고(200), 임시 계정 삭제 후 같은 토큰의 재발급 요청은 401이었다. |
| 실환경 인수 | 배포 주소에서의 접속, Android의 권한·물리 마이크, 발표 거리에서의 5분 추적과 단절 복구가 남았다. |
